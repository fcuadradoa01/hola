# FP Informática y Comunicaciones

Repositorio de apuntes, chuletas, laboratorios guiados y material didáctico orientado a la familia profesional de **Informática y Comunicaciones**.

El objetivo es recopilar recursos prácticos que ayuden a estudiantes, docentes y profesionales a adquirir competencias reales en administración de sistemas, redes, ciberseguridad, virtualización, cloud y automatización.

> "La teoría se olvida. Lo que se despliega, se rompe y se repara es lo que realmente se aprende."

## Contenido

Este repositorio incluye:

- 📚 Apuntes teóricos.
- 📝 Chuletas y guías rápidas.
- 🧪 Laboratorios guiados paso a paso.
- 🖧 Escenarios de redes.
- 🔐 Prácticas de ciberseguridad.
- ☁️ Laboratorios de virtualización y cloud.
- 🐧 Administración de sistemas Linux.
- 🪟 Administración de sistemas Windows.
- 📦 Contenedores y automatización.
- 📄 Plantillas y documentación técnica.
